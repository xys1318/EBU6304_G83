TA Recruitment System

Version 4.0.4 | Group ID: G83

System Architecture

The TA Recruitment System is a lightweight web application built using Java Servlet 4.0 and JSP technology. It follows a simple three-tier architecture:

  • Presentation Layer: HTML5, JavaScript, and CSS3 for the user interface
  • Business Logic Layer: Java Servlets handling HTTP requests and responses
  • Data Storage Layer: JSON file-based storage (WEB-INF/data/storage.json)

Required Environment

  • Java Development Kit (JDK) 11 or higher
  • Apache Maven 3.6 or higher
  • Application Server: Jetty (embedded) or Apache Tomcat 9+

Main Functional Modules

Authentication Module
User login, registration, and role-based access control. Supports three roles: TA, MO, and Admin.
Job Management Module
Create, edit, delete, and view job listings. Managers can post new job opportunities.
Application Tracking Module
Submit applications, track application status, and manage the recruitment workflow.
Chat System Module
Communication between applicants and recruiters/managers.
Profile Management Module
Update personal information, resume management, and theme customization.
Admin Dashboard Module
Comprehensive admin features including TA workload overview, operation timeline, data export, and user management.

Role-Based Access Control

The system supports three distinct user roles:

Role Description Key Features
TA
(Teaching Assistant)		 Job applicants seeking TA positions Browse jobs, apply for positions, manage resume, view application status, chat with MO
MO
(Management Officer)		 Recruitment managers handling TA hiring Post jobs, review applications, approve/reject candidates, chat with TAs
Admin
(System Administrator)		 System administrators overseeing operations Manage users, export data, view TA workload overview, operation timeline

AI Features

Note: This system does NOT include any AI features. All processes (application, review, decision) require human operation.

  • No AI image generation (uses local assets instead)
  • No LLM/ChatGPT integration
  • No machine learning or NLP features

Data Storage

All application data is stored in a JSON file located at:

WEB-INF/data/storage.json

JSON Structure: The storage file contains a single JSON object with the following main keys:

  • users - Array of user profiles with authentication credentials
  • jobs - Array of job postings
  • applications - Array of job applications
  • messages - Array of chat messages

Backup Instructions: To backup the data, simply copy the storage.json file to a safe location. For automated backups, consider implementing a scheduled task to copy this file periodically.

API Endpoints

The system provides REST-like API endpoints via servlets:

GET /api/storage
Retrieves all stored data as JSON
POST /api/storage
Writes JSON data to storage file
OPTIONS /api/storage
Handles CORS preflight requests

Testing Framework

The system includes comprehensive unit and integration tests using:

  • JUnit 5 - Testing framework for unit and integration tests
  • Mockito - Mocking framework for HTTP requests/responses
  • Gson - JSON parsing for test data manipulation

Test Coverage:

Servlet Layer Tests
Tests for StorageSyncServlet using Mockito to mock HttpServletRequest and HttpServletResponse
Service Layer Tests
Tests for JSON file I/O operations using JUnit 5 @TempDir for temporary directories
Integration Tests
End-to-end workflow tests covering user registration, job posting, application submission, and chat system

Test Execution:

mvn test                           # Run all tests
mvn test -Dtest=StorageSyncServletTest   # Run specific test class
mvn test -Dtest="com.ta.recruitment.servlet.*"  # Run tests by package

Building and Running

Build with Maven:

mvn clean install -DskipTests

Run with Jetty:

mvn jetty:run

Deploy to Tomcat:

mvn clean package
copy target/ta-recruitment-system.war TOMCAT_HOME/webapps/

Generate Javadoc:

mvn javadoc:javadoc

Access URLs

  • Login: http://localhost:8082/ta/login.html
  • Home: http://localhost:8082/ta/
  • Admin Dashboard: http://localhost:8082/ta/admin_dashboard.html
  • Javadoc: target/site/apidocs/index.html
